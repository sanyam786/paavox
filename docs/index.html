Project Overview

Contiq is an AI-powered content creation and publishing platform built for social media creators and brands. It provides a suite of 15 specialised AI agents that cover the full content lifecycle — from trend discovery and ideation, through creation and repurposing, to scheduling, publishing, and analytics.

Every agent is backed by Anthropic Claude as the LLM and optionally augmented with real-time web search via Tavily. The platform supports multi-brand management, direct publishing to Instagram, Facebook, LinkedIn, Twitter, and TikTok, and includes a no-code Pipeline system that chains multiple agents together in a single workflow.

ℹ️ The platform is branded as Contiq (content + IQ). All authentication is handled by Clerk and user data is stored in Supabase PostgreSQL with Row Level Security.

Request Flow

  1. Auth — Clerk issues a JWT on sign-in. The frontend stores it and sends it as Authorization: Bearer <token> on every API request.
  2. Backend auth middleware — get_current_user_id() verifies the Clerk JWT (RS256), extracts the user ID, and upserts the user into the users table on first access.
  3. Agent execution — The endpoint instantiates the relevant agent class, calls agent.run(request), saves results to content_items, and returns the response.
  4. Social posting — posting_service.py dispatches to the correct platform API using stored OAuth tokens from social_connections.

Base Agent Pattern

Every agent extends BaseAgent which provides:

class BaseAgent:
    def __init__(self):
        self.client = anthropic.Anthropic(api_key=settings.ANTHROPIC_API_KEY)

    def _chat(self, system: str, user: str, max_tokens: int = 1500) -> str:
        """Synchronous Claude call. Agents call this directly."""
        response = self.client.messages.create(
            model="claude-sonnet-4-6",
            max_tokens=max_tokens,
            system=system,
            messages=[{"role": "user", "content": user}],
        )
        return response.content[0].text

    async def run(self, request) -> ...:
        raise NotImplementedError
⚠️ _chat() is synchronous. Agents that need to do blocking I/O (yt-dlp, ffmpeg) wrap those calls in loop.run_in_executor(None, lambda: ...) to avoid blocking the event loop.

Performance Notes

  • Composite index idx_content_items_user_created on (user_id, created_at DESC) ensures the content library query is an index scan rather than a full table scan.
  • get_all_content() has a hard .limit(50) to prevent statement timeouts on Supabase free tier (8s limit).
  • RLS is disabled on notifications table because Supabase's service key does not bypass storage-layer RLS policies in the same way it does for PostgREST.

Social OAuth Flow

When connecting a social platform (Instagram, Facebook, LinkedIn, Twitter):

  1. User clicks "Connect" in Settings → redirected to platform OAuth page
  2. Platform redirects back to /oauth/success?platform=...&code=...
  3. Backend exchanges the code for access/refresh tokens via social_service.py
  4. Tokens stored in social_connections table; used later by posting_service.py

Pipeline

The Pipeline is a no-code multi-agent workflow builder. Users create a pipeline from a topic and the system sequentially runs: Trend Research → Content Writing → Caption Generation → Video Creation → Posting Schedule.

How It Works

  • User creates a pipeline with a topic/niche on /pipeline.
  • Each step is an AI agent with its output feeding into the next step as context.
  • The pipeline page (/pipeline/[id]) shows each step with live status, output preview, and controls to move to the next step.
  • On the final step (Posting Schedule), the generated video URL and caption are pre-filled into the schedule agent.
  • Pipeline results are saved to content_items with type = "pipeline" and linked by pipeline_id.

Trend Agent — In Depth

The Trend Agent combines real-time web search with LLM analysis to surface the most actionable trending topics for a given niche.

Inputs

FieldTypeDescription
nichestringCreator's content niche (e.g. "fitness", "personal finance")
timeframe24h / 7d / 30dSearch window
platformsstring[]Platforms to target (default: instagram, twitter, linkedin, tiktok)
include_viralbooleanIf true, runs a second Tavily search for cross-niche viral moments and asks Claude to mix in 2 "viral" trends
location_scopebrand / global"brand" uses the brand's saved location; "global" searches worldwide
brand_voice, bio, locationstringInjected from user settings for personalised results

LLM Strategy

  • Tavily search query: trending topics {niche} content creators social media {location} {timeframe}
  • When include_viral=true: second search for viral content social media trending {location} {timeframe} challenges memes
  • Claude is asked to return exactly 5 trends with type: "niche" | "viral", scored 1–10, with content ideas specific to the creator's niche and 5 hashtags each.

Output

  • 5 trend topics, each with score, platforms, 3 content ideas, 5 hashtags, and a trend_type
  • Viral trends are visually distinguished with 🔥 badge and orange ring in the UI
  • Each trend can be saved to the content library or used to "Generate caption for this trend →"

Competitor Analysis — In Depth

Researches any competitor brand and produces a structured gap analysis comparing their strategy to yours.

Research Process (3 Tavily searches)

  1. General strategy: {competitor} brand social media content strategy {niche}
  2. Content & platforms: {competitor} {platforms} posts content type format audience
  3. Audience & positioning: {competitor} target audience brand positioning {niche}

Output Sections

  • Competitor overview — 2–3 sentence summary of who they are
  • Their content strategy — 4 bullet points on format, tone, topics, cadence
  • Strengths — 3 things they do well
  • Weaknesses — 3 blind spots or gaps
  • Content gaps — 3–5 specific gaps with priority (High/Medium/Low) and a tailored opportunity for you
  • Your advantages — what you do or can do better
  • Recommendations — 4 numbered actionable steps

Image Generator — In Depth

Uses Fal.ai FLUX model to generate images from text descriptions.

Supported Styles

  • Photorealistic — DSLR-quality photography look
  • Digital Art — Illustrated, vibrant digital artwork
  • Cinematic — Movie still, dramatic lighting
  • Minimalist — Clean, simple compositions

Claude first rewrites the user description into an optimised image generation prompt before passing it to Fal.ai, incorporating style, mood, lighting, and platform composition hints.

Video Creator — In Depth

Two-Step Process

  1. Script generation (Claude) — Given a topic (or AI VIDEO PROMPT extracted from a Reels/TikTok script), Claude generates a cinematic visual description and spoken words for a single-scene short video.
  2. Video rendering (Fal.ai) — The visual description is sent to Fal.ai's video model. Supported aspect ratios: 9:16 (Reels/TikTok), 1:1 (Instagram), 16:9 (YouTube). Duration: 5s or 10s.

Fallback

If Fal.ai video generation fails, the agent falls back to generating a cover image using FLUX and returns video_error explaining the failure. The frontend shows the cover image with an error badge.

On success, a push notification is created (notifications table) with a link to /content so the user is alerted when the video is ready.

Persona Builder — In Depth

Creates a detailed target audience persona from minimal inputs. Outputs 10 structured sections: persona name, tagline, demographics, psychographics, pain points, goals, content habits, what resonates, what to avoid, and a narrative "day in the life" paragraph. Schedule Agent — In Depth

Key Features

  • Optimal time recommendations — Claude suggests the best posting times for each selected platform based on niche and audience timezone.
  • Media detection — Automatically detects whether the content URL is a video (mp4/mov/etc.) and switches to video posting APIs.
  • Post Now — Dispatches to Instagram, Facebook, LinkedIn, and Twitter APIs in parallel. Per-platform status chips show success/failure. The "Post Now" button stays green and disabled once all platforms are posted.
  • Video support — Instagram (Reels via media_type: REELS, polls until FINISHED), Facebook (/videos?file_url=), LinkedIn (feedshare-video recipe).
  • Pipeline integration — When navigated from a Pipeline step, the media URL, caption, and hashtags are pre-filled.

Analytics Agent — In Depth

Aggregates performance data from connected social platforms and your content history, then uses Claude to generate strategic recommendations. Shows metrics like top-performing content types, best platforms, engagement rates, and growth trends over time.

Collab & Outreach — In Depth

Generates collaboration partner profiles and personalised outreach messages. Inputs: your niche, collaboration type (guest post, co-created video, shoutout, etc.), and target audience. Claude produces 3–5 ideal collaborator profiles with background context and a ready-to-send DM or email pitch.

Influencer Manager — In Depth

Discovers influencer profiles within a niche filtered by audience size tier (nano / micro / macro / mega). Claude generates detailed profiles including estimated engagement rates, content style, audience demographics, and a personalised partnership pitch for each profile.

Comment Reply — In Depth

Paste a comment (or batch of comments) and get on-brand reply options. Supports tone selection (friendly, professional, witty, grateful) and injects brand voice from settings. Useful for maintaining engagement consistency at scale.
